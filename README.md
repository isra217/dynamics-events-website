#  Dynamics Events Website

A responsive and interactive events website built as part of a frontend case study. The project allows users to explore featured events with a clean UI, dynamic elements, and smooth user experience.

---

##  Live Demo
https://isra217.github.io/dynamics-events-website/

---

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Tailwind CSS)  
- JavaScript (Vanilla JS)

---

##  Features

###  Layout
- Top navigation bar with:
  - Logo  
  - Links: Home, Events, Contact  
- Hero section with heading:  
  **Discover Events Near You**

###  Featured Events Section
Displays 6 event cards dynamically.

Each event card includes:
- Event name  
- Date and time  
- Location  
- Short description  
- Register button (UI only)

###  Bonus Features
- Search bar to filter events by name  
- Dynamic event rendering using JavaScript (dummy JSON data)  
- Smooth animations and scroll-based interactions  
- Dynamic hero background image transitions  

---

##  Design
- Clean and modern light UI  
- Fully responsive (mobile, tablet, desktop)  
- Smooth animations and transitions  
- Event-focused layout for better UX
